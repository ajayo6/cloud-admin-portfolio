The aim of this project is to deploy a secure Linux web server
The cloud platform taken is AWS 
The region is South Africa which is the closest to my location Ghana
I am using a single-server architecture
STEPS
create your own cloud account
create a virtual machine
configure the cloud firewall
connect to your server
update your Linux server
check a non-root administrator
configure the firewall
secure the SSH
enable AppArmor
enable Fail2ban
Test for all authenticaton like the SSH and root login
Then minimize cost
